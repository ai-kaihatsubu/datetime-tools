# 018-countdown-timer｜イベントカウントダウン

目標日時までの残り時間を「あと○日○時間○分○秒」でリアルタイム表示するツールです。

## 主な機能

- イベント名と目標日時を登録し、複数イベントをカード一覧で管理
- Date.nowベースで1秒ごとに残り時間を更新
- 目標日時を過ぎたイベントは「経過: ○日○時間○分○秒」と表示
- 登録内容をlocalStorageに自動保存
- ダーク/ライトモード、PWA対応、完全クライアントサイド・無送信

## ファイル構成

雛形 `factory/product-template/` をベースに、`app.js`へカウントダウンロジックを実装。
他ファイル（`style.css`/`monetization.js`/`manifest.webmanifest`/`sw.js`/法務ページ）も
本製品向けに設定済み。
