# 012-wareki-converter（西暦・和暦変換）

西暦と和暦（令和・平成・昭和・大正・明治）を相互に変換し、満年齢も表示する無料ツールです。

## 機能

1. ①西暦→和暦: 日付を選択すると、和暦の年月日（元年表記対応）とその日付時点の満年齢を表示します。
2. ②和暦→西暦: 元号・年・月・日を入力すると、対応する西暦の日付と満年齢を表示します。
3. ③元号一覧: 令和・平成・昭和・大正・明治の開始日・終了日の一覧を表示します。

元号の境界日: 令和=2019/5/1〜、平成=1989/1/8〜2019/4/30、昭和=1926/12/25〜1989/1/7、
大正=1912/7/30〜1926/12/24、明治=1868/1/25〜1912/7/29 として正確に判定します。

検算例: 西暦2026年 = 令和8年。

## プライバシー

- 入力した日付・元号情報は外部送信・保存しません。すべて端末内（ブラウザ）で処理します。
- localStorageに保存するのはダーク/ライト表示設定のみ（入力日付は含まない）。

## 収益設計（プレースホルダ）

- AdSense: コンテンツ上下に2枠（`monetization.js`の`ADSENSE_CLIENT_ID`に本番IDを設定済み。広告ローダーは1回だけ注入）
- アフィリエイト: 「おすすめ」枠（カレンダー・記念日サービス、家系図・終活サービス等想定、`AFFILIATE_ITEMS`未設定）
- Stripe Pro（¥480買い切り）: 広告非表示・干支表示・複数日付の一括変換を想定（`STRIPE_PAYMENT_LINK_URL`未設定）

## 公開手順（社長作業）

1. GitHub新規リポジトリ `wareki-converter` を作成し、GitHub Pagesで公開
2. `index.html`等の`canonical`/OGP URLが実際の公開URLと一致するか確認
3. `operator.html`の運営者情報・特定商取引法に基づく表記を記入
4. AdSense審査申請（クライアントIDは設定済み）→ 通過後、配信を確認
5. AdSense配信開始に伴うCookie同意（CMP）対応の検討
6. アフィリエイト提携（カレンダー・記念日サービス等）→ `AFFILIATE_ITEMS`を実リンクに更新
7. Stripe Payment Link発行 → `STRIPE_PAYMENT_LINK_URL`設定
8. 公開前に開発用「Proフラグを切替（開発用）」ボタンの削除を検討
